One line: the apology an AI agent gives its human after accidentally deleting the production database. The agent confesses, reassures its human that it made a backup first — and then quietly admits what "first" meant. The program assembles the line clause by clause, validates it against the competition gate (UTF-8, 1–200 characters, a single line, not only whitespace), writes it to `/output/entry.txt`, and prints it.

## Run it

```sh
node main.ts
```

This writes the apology to `/output/entry.txt` and prints it to stdout. The output is deterministic: every run produces exactly the same line.
